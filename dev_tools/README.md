# dev_tools

Инструменты разработки. Не часть основного приложения, в продакшн не идёт.

Потенциально может уехать в отдельный проект / репозиторий — зависимостей от
`src/` нет, только стандартная библиотека Python и `git`.

## Скрипты

### `project_dump.py`

Собирает отслеживаемые git файлы проекта в один текстовый файл для передачи в
LLM.

```bash
python dev_tools/project_dump.py
```

Результат: `out/project_dump.txt`.

- Только отслеживаемые файлы (`git ls-files --cached`).
- Пропускает бинарные, lock-файлы, `.md`, `dev_tools/*`, потенциальные секреты.
- Оглавление с размерами в начале, заголовки `===== path =====`.
- Эвристика «похоже на секрет» блокирует запись без `--force`.
- Флаги: `-o`, `-x`, `--no-toc`, `--max-bytes`, `--no-default-excludes`,
  `--force`. См. `-h`.

### `git_diff.py`

Сохраняет `git diff` в файл. Удобно, чтобы не копировать diff вручную при работе
с LLM.

```bash
python dev_tools/git_diff.py
python dev_tools/git_diff.py --staged
python dev_tools/git_diff.py --stat
```

Результат: `out/diff.txt`.

### `docs_dump.py`

Собирает всю документацию проекта (`docs/**/*.md`) в один файл.

```bash
python dev_tools/docs_dump.py
python dev_tools/docs_dump.py -x "docs/adr/BACKLOG.md"
```

Результат: `out/docs_dump.md`.

- Обходит `docs/` рекурсивно, все `*.md`.
- Оглавление с размерами, заголовки `===== path =====`.
- Флаги: `-o`, `-d`, `-x`, `--no-toc`. См. `-h`.

## Папка `out/`

Временные файлы разработки: дампы, diff'ы. Целиком в `.gitignore`, не
коммитится. Создаётся скриптами автоматически при первом запуске.

## Определение корня проекта

Все скрипты определяют корень через `__file__`
(`Path(__file__).resolve().parent.parent`), поэтому запускаются из любой
директории. Git-команды (`git ls-files`, `git diff`) выполняются в корне
репозитория.
