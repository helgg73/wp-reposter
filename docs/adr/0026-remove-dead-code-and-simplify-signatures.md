# ADR 0026: Удаление мёртвого кода и упрощение сигнатур

- **Status:** Accepted
- **Date:** 2026-09-17
- **Related:** ADR 0004, 0012, 0020, 0025
- **Stage:** 2b (побочная задача)

## Context

При ревизии кода после завершения Этапа 2 и в ходе работ Этапа 2b
обнаружены элементы, которые не используются ни в production-коде,
ни в тестах:

1. **`FieldMapping` (`src/models.py`)** — класс определён, и поле
   `MaxChannelConfig.field_mapping` объявлено, но нигде не читается.
   `MaxExporter.format_post()` формирует словарь `data` с жёстко
   закодированными ключами `title`/`content`/`link`/`published`,
   игнорируя `self.config.field_mapping`. Класс вводит в заблуждение:
   кажется, что маппинг настраивается, но фактически — нет.

2. **Параметр `secrets` в `check_sources()` (`src/main.py`)** —
   принимается, но внутри функции не используется. `secrets`
   нужен только на этапе инициализации `MaxExporter`.

3. **`self.bot_token` в `MaxExporter.__init__` (`src/exporter.py`)** —
   сохраняется как атрибут, но читается только в момент создания
   `Bot(token=self.bot_token)`. После этого не используется.

`ExportConfig` (`src/models.py`) **остаётся** — это осознанная
точка расширения под будущие каналы экспорта (ADR 0012, Этап 3).

## Decision

1. **Удалить `FieldMapping` и поле `MaxChannelConfig.field_mapping`.**
   Если в будущем понадобится настраиваемый маппинг — вернуть
   вместе с реальным использованием в `MaxExporter.format_post()`.
   YAGNI: не храним «задел», который не работает.

2. **Убрать параметр `secrets` из сигнатуры `check_sources()`**
   и из соответствующего вызова в `main()`.

3. **Не сохранять `self.bot_token` как атрибут** — передавать
   `bot_token` напрямую в `Bot(...)` внутри `__init__`.

4. **`ExportConfig` оставить без изменений.**

Изменения не затрагивают поведение: только чистка мёртвого кода
и упрощение сигнатур. Тесты, покрывающие публичное поведение,
должны остаться зелёными без правок.

## Done criteria

- `grep -r "FieldMapping" src/ tests/` не находит совпадений.
- `grep -r "field_mapping" src/ tests/` не находит совпадений.
- `check_sources` в `src/main.py` вызывается без `secrets`.
- `MaxExporter.__init__` не создаёт атрибут `self.bot_token`.
- `uv run ruff check` — без ошибок.
- `uv run pytest` — все тесты зелёные, покрытие не снизилось.

## Not to touch

- `ExportConfig` — оставляем как есть (точка расширения под Этап 3).
- `Secrets` — оставляем как есть (используется в `main()`).
- Тесты — правки не требуются, если они не ссылаются на удалённые
  сущности. Если ссылаются — обновить минимально.
