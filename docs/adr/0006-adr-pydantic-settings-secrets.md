# ADR 0006: Хранение секретов — pydantic-settings + .env

- **Status:** Accepted
- **Date:** 2026-09-15
- **Related:** ADR 0012 (единый источник моделей)

## Context

Токены ботов и ID чатов не должны попадать в публичный репозиторий. Рассматривались хардкод, YAML-конфиги и переменные окружения.

Прямые альтернативы:

1. **Хардкод в коде** — секреты в Git, недопустимо.
2. **YAML-конфиг** — легко закоммитить, нет валидации типов.
3. **Только env-переменные** — неудобно для локальной разработки.
4. **pydantic-settings + `.env`** — стандарт 12-Factor App, валидация типов, удобно локально.

## Decision

Использовать **pydantic-settings** с файлом `.env` для секретов.

Реализация:

- **Модуль:** `src/models.py` → `Secrets(BaseSettings)` — единственный источник (см. ADR 0012)
- **Конфиг:** `SettingsConfigDict(env_file=".env", env_file_encoding="utf-8", extra="ignore")`
- **Обязательные поля:** `max_bot_token: str`, `max_chat_id: str`
- **Загрузка:** `src/config.py::load_settings()` → возвращает `(AppConfig, Secrets)`
- **Файлы:**
  - `.env` — в `.gitignore`, не попадает в репозиторий.
  - `.env.example` — в репозитории, должен попадать в дамп TOC. **Сейчас отсутствует в дампе по ошибке скрипта `project_dump.py`** (см. ADR 0001). Чиним скрипт в отдельном чате, не в этом проекте.

## Consequences

**Положительные:**

- Секреты не попадают в Git.
- Автоматическая валидация типов через Pydantic.
- Единый интерфейс для локальной разработки и продакшена.
- Валидация обязательных полей при старте.
- Лёгкая интеграция с Docker (передача через `environment` в compose).

**Отрицательные:**

- Требует создания `.env` перед первым запуском.
- `.env.example` сейчас не в дампе TOC — LLM не видит шаблон. Починим скрипт дампа в отдельном чате.

**Что теперь нельзя / не нужно:**

- Не нужно хардкодить токены в коде.
- Не нужно держать секреты в `config/settings.yaml` — только в `.env`.
- Не нужно парсить `.env` вручную — pydantic-settings делает это сам.
- Не нужно добавлять `.env` в дамп TOC — это осознанное решение (см. ADR 0001, `EXCLUDE_PATTERNS`).
