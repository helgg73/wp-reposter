## Consequences

**Положительные:**
- Чёткий план миграции
- Все задачи трекаются в BACKLOG и ADR 0016
- Нет дублирования: каждый Deferred-пункт имеет явную ссылку на задачу в ADR 0016

**Отрицательные:**
- Требует времени на выполнение

**Что теперь нельзя:**
- Нельзя игнорировать задачи из Deferred без явного решения
- Нельзя дублировать задачи между ADR 0015 и ADR 0016 без ссылок

**Следующий шаг:**
- Выполнить задачи S2-06, S2-07, S2-11, S2-12 на Этапе 2.
