# ADR 0013: Синхронный парсер как осознанное исключение из asyncio

- **Status:** Accepted
- **Date:** 2026-09-15
- **Related:** ADR 0005 (asyncio), ADR 0004 (WP REST API)

## Context

ADR 0005 заявляет «Неблокирующие HTTP-запросы (httpx.AsyncClient)». Однако:

- `src/parser.py` → `WordPressParser.__init__()` использует `httpx.Client` (синхронный).
- `fetch_posts()` вызывается в `src/main.py::check_sources()` **без** `await`.
- Это блокирует event loop на время HTTP-запросов к WordPress.

Прямые альтернативы:

1. **Перевести парсер на `httpx.AsyncClient`** — согласуется с ADR 0005, но требует переписать `fetch_posts`, `_extract_image`, `close`.
2. **Оставить синхронным, зафиксировав исключение в ADR** — проще, честнее, не откладывает Этап 2.
3. **Использовать `asyncio.to_thread(parser.fetch_posts)`** — избыточно для одного источника.

## Decision

**Оставить `WordPressParser` синхронным на Этапе 1.** Зафиксировать исключение в ADR 0005 (ссылка на ADR 0013).

Обоснование:

- Один источник на Этапе 1 — блокировка event loop на 100–300 мс не критична.
- Простота отладки: синхронный `httpx.Client` проще тестировать с `respx`.
- На Этапе 2 (несколько источников) — перевод на `AsyncClient` становится обязательным.
- `maxapi` и `httpx.AsyncClient` в экспортёре уже асинхронные — критичная часть не блокируется.

Реализация:

- **Модуль:** `src/parser.py` — без изменений.
- **Модуль:** `src/main.py::check_sources()` — `parser.fetch_posts(...)` вызывается синхронно.
- **ADR 0005** — дополнен ссылкой: «парсер синхронный, см. ADR 0013».

**Триггер пересмотра:** Этап 2 (несколько источников) или если время одного запроса превысит 1 сек.

## Consequences

**Положительные:**

- Простота отладки и тестирования.
- Не откладывает Этап 2.
- Честная фиксация отклонения от ADR 0005.

**Отрицательные:**

- Event loop блокируется на время HTTP-запросов.
- При нескольких источниках — заметная задержка.

**Что теперь нельзя / не нужно:**

- Не нужно переводить парсер на `AsyncClient` до Этапа 2.
- Не нужно оборачивать `parser.fetch_posts()` в `asyncio.to_thread()` — оверинжиниринг для одного источника.
